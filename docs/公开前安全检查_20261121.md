## 1. 当前被跟踪的敏感类文件

```bash
git ls-files | grep -iE "\.env$|\.env\.|\.db$|\.db-|checkpoints|\.pem$|\.key$|id_rsa|credential|secret"
```
**原始输出**:
```
.env.example
```
→ 只有 `.env.example`(模板)。**无**真实 `.env`、**无**任何 `*.db`、**无**密钥文件被跟踪。

## 2. gitignore 覆盖

```bash
for p in .env backend/dev.db data/checkpoints.db backend/.env; do git check-ignore -v "$p"; done
```
**原始输出**:
```
.gitignore:13:.env      .env
.gitignore:7:*.db       backend/dev.db
.gitignore:10:data/checkpoints.db*      data/checkpoints.db
.gitignore:13:.env      backend/.env
```
→ 四条全部命中忽略规则。

## 3. 历史里是否曾提交过密钥/数据库

```bash
git log --all --full-history --oneline -- .env "*.env" "*.db" "*.db-wal" "*.db-shm" "data/checkpoints.db*"
```
**原始输出**:**空**(105+ 提交全历史无命中)
→ `.env` 与数据库文件**从未进过版本库**,不需要 rewrite history。

## 4. `.env.example` 内容

```bash
cat .env.example
```
**关键行**:`LLM_API_KEY=`(**空值**)、`LLM_PRICE_IN_PER_MTOK=`(空)
→ 纯占位符模板,注释本身写明"只在本机 .env 中出现,绝不写入代码/日志/报告"。

## 5. 真实凭据形态扫描(当前树 + 全历史)

```bash
git grep -InE "sk-[A-Za-z0-9_-]{16,}|ghp_[A-Za-z0-9]{20,}|AKIA[0-9A-Z]{16}|-----BEGIN [A-Z ]*PRIVATE KEY-----" -- .
git grep -InE "sk-[A-Za-z0-9_-]{16,}|ghp_[A-Za-z0-9]{20,}|AKIA[0-9A-Z]{16}" $(git rev-list --all) -- .
```
**唯一命中**(当前树与全历史同一条):
```
backend/tests/test_deploy_artifacts.py:125:
  "  PYTHONDONTWRITEBYTECODE: \"1\"\n  LLM_API_KEY: sk-should-not-exist",
```
**已读上下文核实**:这是**故意注入的哨兵**——该用例把 `sk-should-not-exist` 塞进 CI 配置副本,
断言 `lint_mod.check_ci` **必须报错**,以此证明"CI 不得注入真实凭据"这条门禁有效。
→ **不是真实 key**,是测试固件。无需处理。

## 6. 历史最大 blob(防大文件进仓拖慢 clone)

```bash
git rev-list --objects --all | git cat-file --batch-check='%(objecttype) %(objectname) %(objectsize) %(rest)' \
  | awk '$1=="blob"{print $3, $4}' | sort -rn | head -10
```
**原始输出(前 3)**:
```
0.75 MB  test_feedback/8fafdc73106f1c471565fb52c9ffef1a.png
0.68 MB  test_feedback/eb369528f14152e88de1685a53678857.png
0.56 MB  test_feedback/9b883f3020aeabae502dd7e01607487e.png
```
→ 最大是 QA 截图,**均 < 1MB**。**51MB 的 `data/checkpoints.db` 不在历史里**。
