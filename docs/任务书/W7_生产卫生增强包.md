## W7-1 PII 脱敏管道(出网前 masking,展示反解)

- 新建 `backend/app/pii.py`:探测手机号(1[3-9]xxxxxxxxxx)/身份证(18 位含 X)/收货地址启发式(省市区+路号串),替换为 `[PHONE_1]`/`[ID_1]`/`ADDR_1]` 类占位;维护 per-turn 映射表。
- 挂点:**LLM 出网前**(classify/compose/judge 的输入组装处)统一 mask;AI 回复若含占位符,前端展示前反解还原(chat 响应加 `pii_restore` 映射,前端替换);DB 的 chat_message 存原文(用户自有数据),tool_events payload 存 mask 后文本。
- 测试:三类 PII 各 2 变体 mask 正确;FakeLLM 捕获输入断言只见占位符;反解往返一致;无 PII 输入零改动。

## W7-2 LLM 故障降级(对话路径)

- `real_client` 的 BatchAbort 只服务评测路径;**对话路径**(chat 路由)遇 5xx/429/超时/空正文耗尽 → 返回确定性安全话术("服务暂忙,已记录您的诉求,稍后可重试或转人工")+ `degraded:true` + trace 事件 `llm_degraded`;不裸抛 500。
- 降级话术不得声称已完成任何写操作(反编造护栏同标准)。
- 测试:stub client 抛 500/超时/空正文三路 → 降级响应结构+trace 事件+零写操作;正常路径不受影响。

## W7-3 同义词别名扩展(BM25 口语漏检)

- `retrieval` 加别名表常量(≥12 组:退钱/退差价/赔我→退款;坏了/有问题/瑕疵→质量问题;不想要了/后悔了→七天无理由;快递/物流破了→物流破损;尺码不对/穿不了→尺码换货 等),tokenizer 查询侧扩展(索引侧不动,保持条款原文)。
- 定标:造 ≥6 个口语问句(含 2 个修复前 no_hit 的),断言修复后 top1 命中正确 clause_id;阈值若需微调,docstring 更新分布依据(数字可复算)。
- 测试:别名命中+原词不回归+未覆盖问句仍 no_hit。

## W7-4 Copilot 辅助坐席(工作台建议回复)

- `GET/POST /api/b/tickets/{id}/suggest`:基于工单转录+命中政策(FakeLLM 模板,标 MOCK)生成 `{summary, suggested_reply}`;工作台详情页加"生成建议"按钮+一键填入回复框(可编辑后发送)。
- 建议内容禁止包含承诺性话术(退款到账时间/赔偿金额),guardrails 加禁词校验,命中即剔除该句。
- 测试:suggest 结构+禁词剔除+一键填入的 DOM 断言(test 用 TestClient+前端关键字断言)。

## W7-5 审计链导出

- `backend/scripts/export_audit.py --trace-id X | --refund-id Y`:输出单案审计 JSON:会话事件流、tool_events(含 payload)、confirm_request 状态迁移、退款回执(回读值)、引用条款 id+version、执行者(模型/规则/坐席)、时间线;字段缺失显式 null 不编造。
- 测试:对一条 golden 退款 trace 导出,断言链路完整(感知→分类→检索→工具→确认→执行→回执)。
