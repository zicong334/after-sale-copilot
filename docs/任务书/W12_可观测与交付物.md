## W12-1 /metrics(Prometheus 文本格式,手写零依赖)

- `GET /metrics`(免鉴权但仅 bind 本机时暴露,配置开关):节点延迟分位(p50/p95,按 graph node 分桶)、token 速率计数(agent/judge/real/fallback 分账)、护栏拦截分布(prompt_probe/injection/pii/risky 计数)、工具错误率(按 code)、熔断器状态 gauge、队列深度、缓存命中率。

- 测试:抓取解析(行格式合规:HELP/TYPE/样本行)、计数随请求增长。
