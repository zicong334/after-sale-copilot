## 四项内容

- **U1 售后进度 stepper**:买家回执卡下方 + 工作台工单详情"处理进度"区,纵向四节点时间线(申请→审核→退款/驳回),当前节点高亮、已完成实心、未来空心,节点带时间戳(created_at/decided_at,UTC→本地 HH:MM);无 refund 关联时不渲染(工单 B2 的 refund_request_id 为空场景)。数据从现有 API 取,若字段不足列"需后端回补",不自行改后端。
- **U2 价格红橙药丸徽标**:订单卡金额与工单详情金额改为"¥+大号数字"红橙药丸(主色 #C05621 底白字,圆角同令牌),次要信息(分单位/时间)降灰。
- **U3 状态角标**:工单队列卡片右上角四状态彩色角标(待领取=警示橙/跟进中=主色/待客户回复=信息蓝灰/已关闭=灰),替换现纯文字徽章;键盘可达性保持。
- **U4 快捷词图标**:欢迎屏三快捷词加 16px SVG 线性小图标(画法复用现有角色 SVG 系)。
