## 三、缓做(进 PRD 不做清单,留痕不删)

- 分布式 DB/多实例水平扩展、Redis checkpointer:单机 SQLite 是 PRD 显式选择(D 系列),Capstone 不假装产线拓扑
- Milvus/生产级向量检索:D-02 扩展点已留(embedding 列+VectorBackend 接口),别名扩展先解口语漏检
- LLM 网关多模型热备/语义缓存:key 限定单模型;缓存待真实账单证明价值再做
- 多租户 SaaS/计费、银行流水级审计:PRD 不做清单原有项,无真实支付接入
